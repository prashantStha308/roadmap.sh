   # Building a Personal Blog with Astro

*Posted by Popsy*

Welcome to my little corner of the internet. This post is a quick tour of what I learned while wiring a **frontend** to an **Express backend**.

## What I Built

- A blog list on the home page
- A page per article, rendered from markdown
- Login with a role-based navbar

## The Stack

| Part      | Tool                |
| --------- | ------------------- |
| Frontend  | Astro               |
| Backend   | Express             |
| Storage   | JSON + `.md` files  |

## A Small Snippet

```ts
export const getBlogs = async () => {
	const res = await fetch( "http://localhost:3000/api/blog" );
	const { data } = await res.json();
	return data;
}
```

## Lessons Learned

1. Read the terminal output before guessing
2. A typo in a URL can look like a CORS bug
3. `prerender` decides *when* a page gets built

> Make it work first, make it pretty later.
